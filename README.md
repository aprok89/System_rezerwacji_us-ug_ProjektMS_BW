# System_rezerwacji_us-ug_ProjektMS_BW
Projekt systemu rezerwacji uslug na rok 2026 
Wykonawcy: Mateusz Szostek, Bartosz Wentykier 
Tematyka systemu: System Rezerwacji Usług Masażu
Opis projektu:
System umożliwia rezerwowanie wizyt w salonie masażu. Klient może przeglądać usługi i dostępne terminy, a pracownik oraz administrator mogą zarządzać rezerwacjami.

System posiada trzy rodzaje kont:
Klient: rezerwuje wizyty.
Pracownik: obsługuje swoje wizyty.
Administrator: zarządza całym systemem.

Technologie: PHP, MySQL, HTML, CSS, JavaScript
Uruchomienie krok po kroku:
- Uruchomić Apache i MySQL (np. w XAMPP).
- Zaimportować do MySQL plik z bazą danych.
- Umieścić projekt w folderze htdocs.
- Otworzyć w przeglądarce adres: http://localhost/nazwa-projektu/
